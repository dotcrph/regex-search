## 🎨 Features

* Lightweight
* Fast
* Match highlight
* Scroll through matches
* Flags support
* Vim & Emacs hotkeys

## ⌨️ Hotkeys

> [!IMPORTANT]
> These hotkeys work only while you are inside the extension window (popup), 
i.e. when the extension window (popup) is open

### Vim hotkeys

| Hotkey | Action |
| --- | --- |
| <kbd>Enter</kbd> (in an input field) | Do a search or fill in last input |
| <kbd>j</kbd> | Select next match |
| <kbd>k</kbd> | Select previous match |
| <kbd>n</kbd> | Select next match |
| <kbd>N</kbd> | Select previous match |
| <kbd>q</kbd> | Clear search results and focus on the regex input field |
| <kbd>Enter</kbd> | Close the extension window (popup) |
| <kbd>Esc</kbd> | Close the extension window (popup) |

### Emacs hotkeys

> [!IMPORTANT]
> Unfortunately, there is no way that I know of to disable the default browser 
actions associated with C- and M- characters, so you do not have to press any 
modifier keys before the characters

| Hotkey | Action |
| --- | --- |
| <kbd>Enter</kbd> (in an input field) | Do a search or fill in last input |
| <kbd>n</kbd> | Select next match |
| <kbd>p</kbd> | Select previous match |
| <kbd>s</kbd> | Select next match |
| <kbd>r</kbd> | Select previous match |
| <kbd>g</kbd> | Clear search results and focus on the regex input field |
| <kbd>Enter</kbd> | Close the extension window (popup) |
| <kbd>Esc</kbd> | Close the extension window (popup) |

### General hotkeys

| Hotkey | Action |
| --- | --- |

| <kbd>↓</kbd> | Select next match |
| <kbd>↑</kbd> | Select previous match |
| <kbd>Esc</kbd> | Close the extension window (popup) |
